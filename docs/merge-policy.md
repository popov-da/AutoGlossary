# Политика объединения терминов

## Ключ записи

Для сборки `data/termbase.csv` ключом является `source`, нормализованный через `strip + casefold`. В master и consumer export допускается только одна строка на такой ключ.

## Приоритет статусов

`approved` → `reviewed` → `candidate` → `deprecated` → `rejected`.

Запись с более низким статусом не может заменить перевод записи с более высоким статусом. Поэтому `approved` из `data/volga-pilot-approved.csv` не перезаписывается массовым импортом со статусом `candidate`.

При одинаковом статусе учитываются `confidence`, принадлежность к проектному источнику VOLGA и детерминированная сортировка. Этот выбор нужен только для построения единственного consumer-эквивалента и не считается редакторским разрешением конфликта.

## Разные переводы одного source

Сборщик не удаляет альтернативу молча:

1. выбранный вариант записывается в `target_preferred`;
2. остальные варианты сохраняются в `alternate_targets` master-файла;
3. конфликт записывается в `reports/conflicts.csv` со статусом `manual_review_required`.

После редакторского решения предпочтительный вариант следует добавить в проектный override-файл со статусом `reviewed` или `approved`.

## Омонимы

Consumer contract не поддерживает контекст и требует один `source = одна строка`. Поэтому омонимы нельзя оставлять как одинаковый короткий source с разными переводами.

Предпочтительный порядок исправления:

1. уточнить английский source до реальной словарной фразы: `engine oil pan`, `transmission oil pan`, `flywheel ring gear`, `differential ring gear`, `tire valve stem`;
2. если исходник действительно содержит только неоднозначное слово, выбрать один наиболее общий preferred и оставить варианты в master-метаданных;
3. короткие неоднозначные сокращения (`AP`, `AS` и подобные) не включать без явного редакторского решения.

## Гигиена источников

В коммитируемом master-файле не должны присутствовать полные имена закрытых `.dita`. `source_document` содержит только обезличенные метки корпуса или публичные имена domain-файлов: `N155_CORPUS`, `N165_CORPUS`, `body-repair-welding.csv`.

## Consumer export

`scripts/export_consumer.py` создаёт CSV строго с колонками:

```text
source,target_preferred,status
```

`rejected` не экспортируется. Допустимые статусы: `candidate`, `reviewed`, `approved`, `deprecated`.
