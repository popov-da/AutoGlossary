# AutoGlossary

Открытая англо-русская терминологическая база для автомобильной технической документации и машинного перевода.

## Текущая версия

**v0.2 — 191 термин.**

Покрытие:

- электромобили и зарядная инфраструктура;
- ADAS и автоматизированное вождение;
- AUTOSAR и автомобильная E/E-архитектура;
- CAN FD, SOME/IP, Automotive Ethernet и TSN;
- UDS, DoIP и диагностические службы;
- функциональная безопасность и кибербезопасность;
- модель данных автомобиля COVESA VSS;
- сценарное тестирование ASAM OpenX.

## Файлы

- [`data/termbase.csv`](data/termbase.csv) — полная плоская база;
- [`data/termbase.json`](data/termbase.json) — формат для RAG и программной обработки;
- [`exports/glossary-candidates.csv`](exports/glossary-candidates.csv) — компактный CSV для подключения к переводчику;
- [`reports/ambiguities.csv`](reports/ambiguities.csv) — отчёт по неоднозначным сокращениям;
- [`docs/sources.md`](docs/sources.md) — используемые источники и ограничения.

## Статусы терминов

| Статус | Назначение |
|---|---|
| `candidate` | Предлагаемый перевод, требующий редакторской проверки |
| `approved` | Утверждённый перевод, допустимый для строгого контроля |
| `rejected` | Отклонённый вариант |
| `deprecated` | Устаревший термин или перевод |

Сейчас все русские эквиваленты имеют статус `candidate`. Их нельзя использовать как безусловные массовые замены до проверки по проектной документации.

## Основные поля

| Поле | Описание |
|---|---|
| `term_en` | Английский термин |
| `abbreviation` | Сокращение |
| `term_ru_candidate` | Предлагаемый русский эквивалент |
| `category` | Тематическая категория |
| `term_type` | Тип понятия |
| `source_id` | Идентификатор источника |
| `translation_status` | Статус перевода |
| `confidence` | Уровень уверенности |
| `source_url` | Ссылка на источник |

## Принцип использования

База предназначена для подсказок модели, RAG, поиска и подготовки проектной termbase. Для принудительных замен и автоматического контроля качества следует использовать только записи со статусом `approved`.
